MedProfile-Bouiry

MedProfile-Bouiry is a personal automation utility designed to help manage selected professional notifications and scheduling workflows.

What it does

  • Reads selected Gmail messages in read-only mode to identify relevant professional notifications.
  • Checks Google Calendar availability to help avoid scheduling conflicts.
  • Creates or updates calendar events and reminders when a relevant workflow requires it.
  • Can send optional alert notifications when configured by the user.

Use of Google data

Google account data is used only to provide the functions described above. The application is intended for personal use and does not sell Google user data, use it for advertising, or make it available to data brokers.

Independent application

MedProfile-Bouiry is an independent personal utility and is not presented as an official product of any third-party organization.
