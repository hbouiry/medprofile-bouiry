Privacy Policy

MedProfile-Bouiry — Last updated: 28 September 2026

This Privacy Policy explains how MedProfile-Bouiry accesses, uses, stores and shares information when the user authorizes access to Google services.

1. Purpose of the application

MedProfile-Bouiry is a personal workflow automation utility. It monitors selected professional notifications, checks scheduling availability, creates or updates calendar events, and can generate reminders or alerts.

2. Google data accessed

The application requests only the Google permissions needed for its functions:

  • Gmail read-only access: to read selected incoming messages and identify relevant workflow information such as message identifiers, sender, subject, date/time, scheduling details and links contained in those messages.
  • Google Calendar event access: to read calendar availability and to create, update or manage events related to the workflow.

3. How the data is used

Google data is used only to provide the application's user-facing automation functions, including message detection, conflict checking, event creation, reminders, status tracking and diagnostics.

MedProfile-Bouiry does not use Google user data for advertising, profiling, resale, credit decisions, or data-broker activity.

4. Local storage

The application runs on the user's own computer. Operational data may be stored locally, including OAuth credentials, processed-message identifiers, scheduling slots, event identifiers, workflow status, timestamps, diagnostic logs and limited response text needed for troubleshooting.

These local files remain under the user's control and are retained until the user deletes them or removes the application data.

5. Sharing with third parties

The application does not sell Google user data or make it available to unrelated third parties.

When the optional Pushover alert feature is configured, limited notification data needed to deliver an alert may be transmitted to Pushover, such as a task reference, language label and scheduled date/time. Full Gmail message bodies are not intentionally sent to Pushover by the application.

Google services process data according to the user's Google account authorization and Google's applicable terms and privacy policies.

6. Security

OAuth credentials and operational files are stored locally on the user's computer. The user is responsible for securing the computer, account credentials and local application files. Access can be revoked at any time from the user's Google Account security settings.

7. Data retention and deletion

Operational data stored by the application is retained locally for workflow continuity and diagnostics. The user can delete local logs, state files and OAuth credentials at any time. Revoking Google authorization prevents further access to Google data until the application is authorized again.

8. Limited personal use

MedProfile-Bouiry is intended as a personal utility for its authorized user and is not offered as a general public service.

9. Changes to this policy

This policy may be updated if the application's functionality, data access, storage practices or third-party services change. The revision date shown above will be updated accordingly.

10. Contact

For privacy or support questions concerning MedProfile-Bouiry, contact: hbouiry@gmail.com.
